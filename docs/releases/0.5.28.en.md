# Braket 0.5.28

- New File offers types based on the project and destination folder, with File without extension first and SQL second in every case.
- Choosing a type creates the file directly in the tree with its extension and selects its name for editing. Compound extensions such as .blade.php are preserved when changing the name.
- Suggestions for Laravel, Angular, Node.js, Python and Apache Hive adapt to files in the folder. Dart projects using Hive offer Dart files.
- Fixed an Auto Layout error that could repeatedly widen the window and cause a crash when opening or restoring a project.
- Configurable PHP services support local execution, Docker and Laravel Sail.
- Improved contrast in the service removal confirmation when using the dark theme.
