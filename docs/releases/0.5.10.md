# Braket 0.5.10

- Un único explorador para carpetas, archivos de código y consultas SQL, sin separar Código y Base de datos.
- Conexiones MySQL globales en Configuración, compartidas entre proyectos.
- Cada archivo SQL tiene su propio selector de conexión y recuerda la elección en esta Mac.
- Varias conexiones abiertas simultáneamente, con estado y destino visibles y controles para conectar o desconectar.
- Las conexiones antiguas se importan al abrir proyectos confiables, conservando las contraseñas en el llavero.
- Los scripts independientes siguen disponibles en el árbol. Quitar una conexión deja sus scripts sin asignación, sin elegir otro destino automáticamente.

## English

- One explorer for folders, source files and SQL queries, without separate Code and Database sections.
- Global MySQL connections in Settings, shared across projects.
- Each SQL file has its own connection selector and remembers its selection on this Mac.
- Keep multiple connections open, with visible status and destination and controls to connect or disconnect.
- Legacy profiles are imported when trusted projects are opened, preserving passwords in Keychain.
- Standalone scripts remain available in the explorer. Removing a connection leaves its scripts unassigned instead of selecting another destination automatically.
