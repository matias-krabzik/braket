# Braket 0.5.15

- Codex opens in an editor tab with a session explorer for each project: create, filter, rename, and resume conversations.
- Sessions retain their title, scope, and draft. Resuming a session restores its Codex history, and the selected tab is restored after restarting.
- Requests include bounded context from the active file, selection, open files, and recent process output. The agent can refresh this context while working.
- Navigation between files, databases, automations, and Codex sessions is improved.
- Codex requests for additional access can be declined, approved once, or approved for the session where supported.
- Delivery mode enables network access for the submitted request while retaining the project's authorized folders.
- Workflows can preserve JSON context across nodes, identify each run, and validate the files required from a Codex response.
- The project includes a workflow to prepare bilingual release notes and calculate the next version without publishing. Signing and deployment remain separate steps.
