# Braket 0.5.26

- Transiciones suaves al abrir pestañas de código y resultados, cambiar de proyecto o explorador y mostrar el panel inferior.
- La búsqueda flotante, los pasos del asistente y las secciones de configuración acompañan el cambio de contexto con animaciones breves.
- Los indicadores de carga esperan 180 ms para evitar destellos en operaciones rápidas. Reducir movimiento adapta las transiciones y utiliza indicadores estáticos.
- Las tarjetas de relaciones se despliegan con una transición breve y muestran tiempo de consulta y cantidad de registros. El espacio para el scroll horizontal aparece solo cuando hace falta.
- Los botones de relaciones quedan al extremo derecho de la celda y conservan espacio para el valor. Se incluye una base de ejemplo con claves foráneas simples y compuestas.
