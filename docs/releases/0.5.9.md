# Braket 0.5.9

- Opciones SSL de MySQL más claras, incluyendo «Usar SSL si está disponible» y «Exigir SSL (sin verificar certificado)».
- Parámetros avanzados de conexión: tiempo de espera, CA personalizada, nombre TLS/SNI, certificado y clave de cliente en formato PEM.
- Mensajes de error de certificados con indicaciones para configurar la conexión.
- Compatibilidad con perfiles guardados en versiones anteriores, sin cambiar automáticamente su política SSL.

## English

- Clearer MySQL SSL options, including “Use SSL if available” and “Require SSL (without certificate verification)”.
- Advanced connection settings: timeout, custom CA, TLS/SNI server name, and PEM client certificate and private key.
- Certificate error messages now explain how to configure the connection.
- Existing saved profiles remain compatible and retain their SSL policy.
