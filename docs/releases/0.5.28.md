# Braket 0.5.28

- Nuevo archivo ofrece tipos según el proyecto y la carpeta, con Archivo sin extensión primero y SQL segundo en todos los casos.
- Al elegir un tipo, el archivo aparece directamente en el árbol con su extensión y el nombre seleccionado para editar. Las extensiones compuestas, como .blade.php, se conservan al cambiar el nombre.
- Sugerencias para Laravel, Angular, Node.js, Python y Apache Hive, con variantes según los archivos de la carpeta. Los proyectos Dart que usan Hive ofrecen archivos Dart.
- Corregido un error de Auto Layout que podía ampliar la ventana de forma continua y provocar un cierre al abrir o restaurar un proyecto.
- Servicios PHP configurables con ejecución local, Docker y Laravel Sail.
- Mejor contraste de la confirmación para eliminar servicios en el tema oscuro.
