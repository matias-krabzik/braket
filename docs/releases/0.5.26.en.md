# Braket 0.5.26

- Smooth transitions when opening code and result tabs, switching projects or explorers, and revealing the bottom panel.
- Floating search, wizard steps, and settings sections use brief transitions to accompany context changes.
- Loading indicators wait 180 ms to avoid flashes during fast operations. Reduce Motion adapts transitions and uses static indicators.
- Related-record cards expand with a brief transition and show query duration and record count. Horizontal scrolling reserves space only when needed.
- Relation buttons sit at the far right of each cell with room reserved for its value. A sample database includes simple and composite foreign keys.
