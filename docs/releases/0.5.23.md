# Braket 0.5.23

- Corregidos ⌘C y ⌘V en las celdas seleccionadas de los resultados y en la edición de texto dentro de una celda.
- Copiar obtiene el valor completo, incluidos texto multilínea y números de gran precisión; también funciona en resultados de solo lectura.
- Pegar valida números, fechas, enums y las restricciones de edición, dejando los cambios pendientes para revisar antes de enviarlos a MySQL.
- Copiar entre celdas conserva NULL y DEFAULT como valores especiales, distinguiéndolos del texto literal.
- Incorporada la acción Pegar valor al menú contextual y actualizada la habilitación de Copiar y Pegar en el menú nativo.
