# Braket 0.5.18

- Floating SQL selection toolbar to execute selected text and comment or uncomment lines, with undo and redo.
- Green icons for running SQL statements, selections, and complete files.
- Find with ⌘F and find and replace with ⌘R in a floating editor panel.
- Improved SQL highlighting, matching parentheses, guides, automatic closing, and formatting with ⌥⌘L.
- SET statements show evaluated variable values inline without opening result tabs.
- Inline result editing with keyboard navigation and field-specific controls, including dates and enum values.
- The Now button uses the MySQL server clock and respects DATE, DATETIME, and TIME fields.
- Row changes use primary keys, retain conflict detection, and show previous and new values.
- Double-clicking an explorer table opens its query; a single click expands or collapses its structure.
