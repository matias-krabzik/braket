# Braket 0.5.25

- Query results show a link indicator on values belonging to foreign keys declared in MySQL.
- A fixed button at the far right of each row opens an inline card with the related record without covering values or losing the original results.
- Command-click a related row or cell to open its query in a new tab. When several relationships are available, choose the destination; the card also provides an open-in-tab action.
- Supports composite keys, column aliases, cross-database references, and NULL values. Previews are read-only and use a connection independent of the editor session.
- Related cards keep their state when switching tabs, display loading and errors, and adapt their height to their content. Cell editing and clipboard shortcuts remain available.
