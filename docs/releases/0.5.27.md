# Braket 0.5.27

- Terminal integrada con múltiples pestañas, shell zsh y sesiones independientes. Minimizar el panel o cambiar de proyecto mantiene las sesiones activas.
- Las pestañas de terminal, su orden, selección y directorios se recuerdan por proyecto. Al volver a abrir Braket se crean shells nuevos, sin volver a ejecutar los comandos anteriores.
- Variables de entorno compartidas por proyecto y propias de cada terminal, con prioridad para estas últimas. Los valores se guardan en el Llavero de macOS; los cambios se aplican a sesiones nuevas o reiniciadas.
- Confirmación antes de cerrar o reiniciar una terminal con procesos activos. Las pestañas aceptan clics en el nombre y sus márgenes, con acciones independientes para configurar y cerrar.
- Administrador global de procesos con búsqueda, filtros por proyecto, puertos, logs y edición de la configuración de ejecución. Los procesos se mantienen activos al cambiar de proyecto.
- El administrador de procesos comienza integrado y puede abrirse en ventana independiente. Al cerrar la ventana del IDE con procesos activos queda disponible su administrador; los colores respetan el tema elegido.
- Configuración reorganizada en General, Apariencia y Textos, Editor, SQL, Conexiones y Actualizaciones. El inicio y el timeout tienen sus secciones propias.
- Cinco tipografías reales para código y resultados, con tamaño y negrita independientes: SF Mono, Menlo, JetBrains Mono, Fira Code y Source Code Pro.
- Mejoras en las áreas de clic de botones y pestañas, en la presentación de relaciones SQL y en los separadores del encabezado.
