# Braket 0.5.21

- New connections are private to their project by default, with independent per-file selections and recent connections.
- Search the Shared catalog to add connections to each project without duplicating profiles or passwords.
- Existing connections remain shared and can be explicitly added to projects; connections declared by trusted legacy projects are retained when imported.
- Removing a shared connection from a project preserves its profile, password, and associations with other projects.
- Connection editing shows private or shared status and allows sharing; profiles used by other projects can be duplicated to create private variants.
- Previous results cannot be rerun using connections that have not been added to the current project.
- Fixed SQL variable expansion before pagination, preserving values and query logging.
