# Braket 0.5.8

- Zoom de interfaz nítido del 80 % al 150 %, con comandos ⌘+, ⌘− y ⌘0. El editor, los paneles y la pantalla de inicio dibujan el texto al tamaño elegido.
- Al salir de Braket se conserva el proyecto y las pestañas abiertas. Solo se advierte antes de cerrar cuando hay ejecuciones activas.
- Vista previa de Markdown con editor dividido y zoom independiente; vistas previas de imágenes.
- Gestión de archivos desde el explorador del proyecto.
- Automatizaciones integradas en pestañas, con editor contextual, ejecución de scripts, pasos de Codex y acciones sobre archivos.

Requiere macOS 14 o posterior. Disponible para Apple Silicon e Intel.
