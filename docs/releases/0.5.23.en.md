# Braket 0.5.23

- Fixed ⌘C and ⌘V for selected result cells and text editing inside a cell.
- Copy retrieves the full value, including multiline text and high-precision numbers, and works in read-only results.
- Paste validates numbers, dates, enums, and editing restrictions, staging changes for review before sending them to MySQL.
- Copying between cells preserves NULL and DEFAULT as special values, distinguishing them from literal text.
- Added Paste Value to the context menu and updated Copy and Paste availability in the native menu.
