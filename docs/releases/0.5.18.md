# Braket 0.5.18

- Barra flotante al seleccionar SQL para ejecutar la selección y comentar o descomentar líneas, con deshacer y rehacer.
- Iconos verdes para ejecutar sentencias, selecciones y archivos SQL completos.
- Buscar con ⌘F y buscar y reemplazar con ⌘R en un panel flotante integrado al editor.
- Resaltado SQL mejorado, emparejamiento de paréntesis, guías, cierre automático y formato con ⌥⌘L.
- Los SET muestran el valor evaluado de sus variables junto a la sentencia, sin abrir pestañas de resultados.
- Edición de resultados dentro de la celda con navegación por teclado y controles según el tipo de campo, incluidos fechas y enum.
- El botón Ahora usa la fecha y hora del servidor MySQL y respeta los campos DATE, DATETIME y TIME.
- Cambios de filas basados en la clave primaria, con detección de conflictos y comparación de valores anteriores y nuevos.
- Doble clic en una tabla del explorador abre su consulta; el clic simple expande o contrae la estructura.
