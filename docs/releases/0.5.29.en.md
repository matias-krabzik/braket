# Braket 0.5.29

- Twelve theme families with light and dark variants, based on Graphite, with coordinated colors for the interface, SQL editor, results, terminal, and Processes.
- Choose light or dark appearance manually, or follow macOS changes. Settings let you preview themes before applying or saving.
- Quick theme selector next to Settings, with theme names and an interface thumbnail on hover.
- Node.js services and package.json scripts using npm, pnpm, and Yarn. Choose executables, files, scripts, and arguments in service settings.
- Background discovery of installed Node.js versions and package managers, with a progress indicator. Results are cached and can be refreshed on demand.
- Existing appearance preferences are preserved, and Midnight remains available for people who already use it.
