# Braket 0.5.30

- Read-only Git changes view with grouped repositories, the current branch, and modified, new, and deleted files.
- The sidebar icon shows the number of changed files. The list refreshes in the background and can also be refreshed manually.
- A single reusable tab displays line-numbered differences and lets you navigate between files. Deleted files show an «Archivo eliminado» notice.
- Switching projects preserves open tabs and pending edits during the session. The sidebar width stays consistent when switching explorers.
- The Processes panel can be docked at the bottom or side. The bottom is the default and shares space with Terminal and Results.
- The Processes panel adapts to narrow widths and groups service actions into a menu.
