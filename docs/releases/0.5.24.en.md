# Braket 0.5.24

- Local lists now accept literal values: `SET LIST EMAIL = ['ashlee@example.com', 'nick@example.com'];`. Capturing values from a SELECT remains available.
- Literal lists support text and numbers, preserve numeric precision, and expand safely through `IN ({{EMAIL}})`. They use the same detail, search, and copy pill as captured lists.
- Command-click a table reference in the SQL editor to open its CREATE TABLE definition in a new read-only tab with syntax highlighting and selectable text.
- The explorer action is now named “Abrir definición de tabla” and opens the same tab instead of a modal.
