# Braket

## Funcionalidades

- Integra automatizaciones en pestañas del editor, con un editor contextual de flujos de trabajo y opciones para ejecutar scripts.
- Añade pasos de flujo de trabajo de Codex, vistas previas de imágenes, inspección de flujos JSON y pruebas aisladas de nodos.
- Permite administrar archivos desde el explorador de proyectos y guardar archivos mediante un nodo de flujo de trabajo.
- Añade vista previa de Markdown en un editor dividido, con zoom persistente.
- Permite ejecutar un flujo de trabajo desde el menú contextual del nodo Start.
- Aclara la configuración SSL de MySQL y añade opciones avanzadas de conexión.

## Correcciones

- Corrige la respuesta del gráfico de flujo de trabajo y conserva la sesión del espacio de trabajo abierto al cerrar el IDE.
- Muestra los tamaños de fuente nativos al aplicar el zoom de la interfaz.

## Mantenimiento

- Ajusta CI para ejecutarse solo manualmente, usar firma ad hoc en las pruebas de GitHub Actions y conservar y mostrar los errores completos de verificación.
