# Braket

## Features

- Integrates automations into editor tabs, with a contextual workflow editor and script execution settings.
- Adds Codex workflow steps, image previews, JSON workflow inspection, and isolated node testing.
- Supports file management from the project explorer and saving files through a workflow node.
- Adds Markdown previews in a split editor, with persistent zoom.
- Lets you run a workflow from the Start node’s context menu.
- Clarifies MySQL SSL configuration and adds advanced connection settings.

## Fixes

- Improves workflow graph responsiveness and preserves the open workspace session when quitting the IDE.
- Uses native font sizes when zooming the interface.

## Maintenance

- Updates CI to run only manually, use ad hoc signing for GitHub Actions tests, and retain and display full verification errors.
