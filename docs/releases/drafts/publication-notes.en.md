# Braket

## Features

- Integrates automations into editor tabs, with a contextual workflow editor and script execution settings.
- Adds Codex workflow steps, image previews, JSON workflow inspection, and isolated node testing.
- Adds file management to the project explorer and a workflow node for saving files.
- Adds Markdown preview and split editing.

## Fixes

- Improves workflow graph responsiveness.

## Maintenance

- Updates CI to run manually, uses ad hoc signing for GitHub Actions tests, and preserves and displays complete verification errors.
