# Braket

## Funcionalidades

- Integra automatizaciones en pestañas del editor, con un editor contextual de flujos de trabajo y ajustes de ejecución de scripts.
- Añade pasos de flujo de trabajo para Codex, vistas previas de imágenes e inspección de flujos JSON, además de pruebas aisladas de nodos.
- Permite administrar archivos desde el explorador de proyectos y guardar archivos mediante un nodo de flujo de trabajo.
- Añade vista previa de Markdown y edición dividida.

## Correcciones

- Mejora la capacidad de respuesta de los gráficos de flujo de trabajo.

## Mantenimiento

- Ajusta CI para ejecutarse manualmente, usa firma ad hoc en las pruebas de GitHub Actions y conserva y muestra los errores completos de verificación.
