# Braket — Release notes

## Features

- Automations are integrated into editor tabs, with a contextual workflow editor and script execution settings.
- New Codex workflow steps include image previews.
- The project explorer supports file management.
- Markdown previews include a split editor and persistent zoom.
- JSON workflow inspectors and isolated node testing are available.
- A new workflow node saves files.

## Fixes

- Improved workflow graph responsiveness.

## Maintenance

- CI preserves and displays complete verification errors, uses ad hoc signing for GitHub Actions tests, and runs only on manual request.
