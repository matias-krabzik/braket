# Braket — Notas de versión

## Funcionalidades

- Integración de automatizaciones en pestañas del editor, con un editor contextual de flujos de trabajo y opciones para ejecutar scripts.
- Nuevos pasos de flujo de trabajo para Codex, con vistas previas de imágenes.
- El explorador de proyectos permite gestionar archivos.
- Vista previa de Markdown con editor dividido y zoom persistente.
- Inspectores para flujos de trabajo JSON y pruebas aisladas de nodos.
- Nuevo nodo de flujo de trabajo para guardar archivos.

## Correcciones

- Mejor respuesta del gráfico de flujos de trabajo.

## Mantenimiento

- La CI conserva y muestra los errores completos de verificación, usa firma ad hoc en las pruebas de GitHub Actions y se ejecuta únicamente de forma manual.
