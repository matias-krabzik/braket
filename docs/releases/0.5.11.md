# Braket 0.5.11

- ⌘Enter ejecuta la sentencia SQL completa bajo el cursor, o el texto seleccionado. Una línea vacía no ejecuta otras consultas.
- Resultados acumulados en pestañas, con un panel más amplio, tamaño ajustable, zoom global, texto monoespaciado y columnas redimensionables.
- Doble clic para editar una celda; Enter guarda el cambio pendiente y ⌘Enter abre la revisión de todas las consultas antes de enviarlas.
- Acciones contextuales según la estructura: NULL, DEFAULT, valores ENUM, deshacer, agregar, duplicar y eliminar filas.
- Edición transaccional en tablas InnoDB con filas identificables. Los conflictos revierten el envío y conservan los cambios pendientes.
- Barra lateral para alternar entre archivos y bases de datos, con selección de bases visibles y una base predeterminada por conexión.
- Caché de estructura mediante INFORMATION_SCHEMA y autocompletado de bases, tablas, campos y alias SQL.
