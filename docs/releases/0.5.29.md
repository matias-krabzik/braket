# Braket 0.5.29

- Doce familias de temas con variantes claras y oscuras, basadas en Grafito, con colores coordinados para la interfaz, el editor SQL, los resultados, la terminal y Procesos.
- Apariencia clara u oscura manual, o siguiendo los cambios de macOS. La configuración permite previsualizar los temas antes de aplicar o guardar.
- Selector rápido junto a Configuración, con nombres de temas y una miniatura de la interfaz al pasar el puntero.
- Servicios Node.js y scripts de package.json con npm, pnpm y Yarn. Permite elegir ejecutables, archivos, scripts y argumentos desde la configuración de servicios.
- Detección de versiones instaladas de Node.js y gestores de paquetes en segundo plano, con indicador de progreso. Los resultados se conservan y pueden actualizarse a voluntad.
- Se conservan las preferencias de apariencia existentes y Azul noche sigue disponible para quienes lo usaban.
