# Braket 0.5.19

- SET LIST stores lists of IDs or values within the project for reuse in queries through {{name}}, without creating MySQL variables.
- SET and SET LIST pills open a floating card with search and copying of captured values.
- Copy buttons beside each pill copy the full reference on the left and SQL-formatted values on the right, with a pointing-hand cursor and visual feedback.
- Lists preserve numeric and text types, validate their use in IN clauses, and prevent reuse of incomplete or failed captures.
- Generated queries use readable literals and escape values without CONVERT, preserving conflict detection when editing rows.
