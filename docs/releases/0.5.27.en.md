# Braket 0.5.27

- Integrated terminal with multiple tabs, zsh shells and independent sessions. Minimizing the panel or switching projects keeps sessions running.
- Terminal tabs, order, selection and working directories are remembered per project. Reopening Braket creates fresh shells without rerunning previous commands.
- Shared project environment variables and per-terminal overrides. Values are stored in macOS Keychain; changes apply to new or restarted sessions.
- Confirmation before closing or restarting terminals with active processes. Tab names and padding are clickable, with separate configuration and close actions.
- Global process manager with search, project filters, ports, logs and launch configuration editing. Processes stay active when switching projects.
- The process manager starts docked and can move to an independent window. Closing the IDE window with active processes keeps its manager available; colors follow the selected theme.
- Settings reorganized into General, Appearance and Text, Editor, SQL, Connections and Updates. Startup behavior and timeouts have dedicated sections.
- Five real code and result fonts with independent size and bold options: SF Mono, Menlo, JetBrains Mono, Fira Code and Source Code Pro.
- Improved button and tab hit areas, SQL relationship presentation and header dividers.
