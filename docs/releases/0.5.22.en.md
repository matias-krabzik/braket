# Braket 0.5.22

- Edit single-table results with WHERE subqueries, identifying rows by their primary key while retaining conflict detection and rollback.
- A 60-second initial timeout, configurable at application, project, and SQL file levels, with the most specific setting taking priority.
- File timeouts are remembered after reopening, saving a draft, or relocating a project, and can return to the inherited default.
- Each statement has its own limit, including when running a whole file; running executions keep their original limit.
- Running a whole file replaces previous unpinned results and preserves pinned results.
- Tab menus close the current, other, left, right, unpinned, or all results, confirming pending edits before closing the group.
- More compact result tabs and pin and close buttons with rectangular click areas and hover feedback.
