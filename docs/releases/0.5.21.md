# Braket 0.5.21

- Las conexiones nuevas son privadas del proyecto por defecto, con selección por archivo y recientes independientes.
- Catálogo Compartidas con búsqueda para agregar conexiones a cada proyecto sin duplicar perfiles ni contraseñas.
- Las conexiones anteriores se conservan como compartidas y se agregan explícitamente a los proyectos; las declaradas en proyectos antiguos confiables se conservan al importarlos.
- Quitar una compartida del proyecto conserva el perfil, la contraseña y las asociaciones de los demás proyectos.
- La edición indica si una conexión es privada o compartida y permite compartirla; los perfiles usados en otros proyectos se pueden duplicar para crear variantes privadas.
- Los resultados antiguos no pueden volver a ejecutarse con conexiones que no están agregadas al proyecto actual.
- Corregida la expansión de variables SQL antes de paginar, conservando sus valores y el registro de consultas.
