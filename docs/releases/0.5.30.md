# Braket 0.5.30

- Vista de cambios Git de solo lectura con repositorios agrupados, rama actual y archivos modificados, nuevos y eliminados.
- El icono lateral indica cuántos archivos cambiaron. La lista se actualiza en segundo plano y permite actualizarla manualmente.
- Una única pestaña reutilizable muestra las diferencias con números de línea y permite recorrer los archivos. Los eliminados muestran «Archivo eliminado».
- Al cambiar de proyecto se conservan las pestañas y los cambios pendientes durante la sesión. El ancho lateral se mantiene al alternar exploradores.
- El panel de Procesos puede acoplarse abajo o al lateral. La posición inferior es la predeterminada y comparte espacio con Terminal y Resultados.
- El panel de Procesos se adapta a anchos reducidos y agrupa las acciones de cada servicio en un menú.
- Los iconos de estado identifican los archivos nuevos, modificados y eliminados.
