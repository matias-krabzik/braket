# Braket 0.5.4

- Resaltado de sintaxis específico para Swift, Dart, JavaScript, TypeScript, PHP, SQL, Python, HTML, CSS y otros lenguajes mediante Tree-sitter.
- Resaltado de JavaScript y CSS dentro de HTML, con soporte para módulos y bloques JSON según el atributo `type`.
- Los bloques incrustados conservan su contexto al editar, deshacer y trabajar con etiquetas todavía sin cerrar.
- Mejoras en comentarios multilínea, caracteres Unicode y palabras clave SQL en mayúsculas y minúsculas.
- Análisis incremental en segundo plano y aplicación de colores al área visible para mantener fluida la edición.

Requiere macOS 14 o posterior. Disponible para Apple Silicon e Intel.
