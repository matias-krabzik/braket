# Braket 0.5.15

- Codex se abre en una pestaña del editor y cuenta con un explorador de sesiones por proyecto: crear, filtrar, renombrar y retomar conversaciones.
- Las sesiones conservan su título, alcance y borrador; al retomarlas se recupera el historial de Codex y se restaura la pestaña seleccionada al reiniciar.
- Los pedidos incluyen contexto acotado del archivo activo, selección, archivos abiertos y salida reciente de procesos. El agente puede actualizarlo durante el trabajo.
- Mejora la navegación entre archivos, bases de datos, automatizaciones y sesiones de Codex.
- Las solicitudes de acceso adicional de Codex permiten rechazar, aprobar una vez o aprobar durante la sesión cuando corresponde.
- El modo Entrega habilita la red para el pedido enviado, conservando las carpetas autorizadas del proyecto.
- Los flujos pueden conservar contexto JSON entre nodos, identificar cada ejecución y validar los archivos requeridos de una respuesta de Codex.
- El proyecto incluye un flujo para preparar notas bilingües y calcular la próxima versión sin publicar. La firma y el despliegue siguen siendo pasos separados.
