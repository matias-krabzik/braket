# Braket 0.5.17

- Selector de proyectos junto al nombre de Braket, con búsqueda, recientes y acciones para crear o abrir proyectos.
- Configuración del proyecto en un modal propio, accesible desde el encabezado del explorador de archivos.
- Conexiones de base de datos en una sola fila, con estado de conexión y contador de bases visibles.
- Menú contextual para conectar, desconectar, editar, duplicar, abrir consultas, elegir bases, actualizar estructura y eliminar conexiones.
- Los exploradores recuerdan las ramas abiertas por proyecto. En la primera apertura se muestra solo el primer nivel.
- Tintes de conexiones y carpetas de borde a borde, con mejor espacio alrededor de la selección.
- Editor SQL con indicadores de ejecución, ajuste de líneas y mejoras en la numeración y el historial de deshacer.
- Resultados con encabezados monoespaciados, barras de desplazamiento que reservan su espacio y controles más compactos.
- Al cerrar archivos con cambios, Braket permite guardar, descartar o cancelar.
