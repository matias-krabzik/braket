# Braket 0.5.20

- Corregido el bloqueo de «Instalar y volver a abrir» cuando Configuración está abierta como modal.
- Antes del reinicio, los cambios pendientes de Configuración pueden guardarse, descartarse o conservarse cancelando el cierre.
- La actualización espera a que el modal termine de cerrarse y mantiene las confirmaciones de archivos, consultas y procesos pendientes.
- Los editores de conexión abiertos conservan sus cambios y su bloqueo del cierre hasta que se resuelvan.
