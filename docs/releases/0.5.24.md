# Braket 0.5.24

- Las listas locales ahora admiten valores directos: `SET LIST EMAIL = ['ashlee@example.com', 'nick@example.com'];`. También se mantiene la captura desde un SELECT.
- Los literales admiten texto y números, conservan la precisión y se expanden de forma segura mediante `IN ({{EMAIL}})`. Comparten la píldora de detalle, búsqueda y copia de las listas capturadas.
- ⌘+clic sobre una referencia a una tabla en el editor SQL abre su definición CREATE TABLE en una pestaña nueva de solo lectura, con resaltado y texto copiable.
- La acción del explorador pasa a llamarse «Abrir definición de tabla» y abre esa misma vista en una pestaña, en lugar de un modal.
