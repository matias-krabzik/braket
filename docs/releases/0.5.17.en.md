# Braket 0.5.17

- Project selector next to the Braket name, with search, recent projects, and actions to create or open projects.
- Project settings in a dedicated modal, accessible from the file explorer header.
- Database connections in a single row, with connection status and a visible database counter.
- Context menu to connect, disconnect, edit, duplicate, open queries, choose databases, refresh schemas, and remove connections.
- Explorers remember expanded branches per project. The first opening shows only the top level.
- Full-width connection and folder tints, with more space around the selection.
- SQL editor with execution indicators, line wrapping, and improvements to line numbering and undo history.
- Results with monospaced headers, scrollbars that reserve their space, and more compact controls.
- Closing modified files offers save, discard, and cancel actions.
