# Braket 0.5.19

- SET LIST permite guardar listas de IDs o valores en el proyecto y reutilizarlas en consultas con {{nombre}}, sin crear variables en MySQL.
- Las píldoras de SET y SET LIST abren una tarjeta flotante con búsqueda y copia de los valores capturados.
- Botones de copia junto a cada píldora: referencia completa a la izquierda y valores en su formato SQL a la derecha, con cursor de manito y confirmación visual.
- Las listas conservan los tipos numéricos y de texto, validan su uso en IN y evitan reutilizar resultados incompletos o fallidos.
- Las consultas generadas usan literales legibles y escapan los valores sin CONVERT, conservando la detección de conflictos al editar filas.
