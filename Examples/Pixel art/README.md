# Bosque nocturno

Abrí `Bosque nocturno.kzk` en Braket y luego `bosque.pxa` desde el árbol.

Ejemplo de 64 × 64 píxeles, cuatro capas y ocho fotogramas. Empieza en el tercer fotograma, con piel de cebolla activada: dos anteriores y uno siguiente. El humo y una luciérnaga cambian de posición. Los colores del arte son libres; incluye una paleta de 16 colores para continuar dibujando.

La escena es una recreación de la cabaña del mockup; el mockup no contenía un documento editable original. `bosque-referencia.png` conserva la ilustración generada que se importó al ejemplo. La capa Luces queda preparada para añadir animación propia.
